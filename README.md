## 최종적으로 해결한 문제

학교에서는 인사이동이나 보직 변경이 있을 때마다 누구나 새로운 업무의 초보가 됩니다. 전임자의 자료와 공문은 남아 있어도, 무엇을 언제부터 해야 하는지 파악하기 어렵습니다. 개인의 경험에 의존하던 업무 인수인계를 학교의 지식으로 축적하는 문제를 풀고자 했습니다.

### 어떻게 풀었나요?

GAM은 공문과 매뉴얼을 분석해 업무·일정·관련 문서를 하나의 업무 지도로 구조화합니다. 전년도 처리 사례와 동료 교사의 실무 경험까지 연결해 지금 해야 할 일을 보여줍니다. AI에게 질문하면 실제 업무 문서를 근거로 필요한 정보를 찾아 답해줍니다.

## 핵심 기능

- **내 업무 홈**: 담당 업무를 기준으로 지금 해야 할 일과 곧 준비할 일을 한눈에 보여줍니다.
- **연간 업무 지도**: 1년 동안의 업무 흐름과 현재 위치를 월별로 시각화합니다.
- **업무 체크리스트**: 업무별 처리 절차와 해야 할 일을 순서대로 안내합니다.
- **관련 자료 통합**: 공문, 매뉴얼, 양식, 전년도 처리 사례를 업무별로 연결합니다.
- **AI 감**: 실제 업무 문서를 근거로 질문에 답하고 출처를 함께 제시합니다.
- **문서 자동 분석 및 업무카드 생성**: 새로 받은 공문이나 매뉴얼에서 업무와 일정을 자동으로 추출하고, 분석한 문서를 바탕으로 업무 카드와 연간 일정을 자동 구성합니다.
- **선생님들의 감**: 동료 교사의 자료와 실무 경험을 공유하고 내 업무에 연결할 수 있는 지식공유 서비스입니다.

## 사용 흐름과 사용 방법

1. 사용자가 현재 맡은 업무와 담당 시기를 등록합니다.
2. 내 업무 홈에서 지금 해야 할 일과 다가오는 일정을 확인합니다.
3. 연간 업무 지도에서 담당 업무의 전체 흐름을 파악합니다.
4. 필요한 내용은 AI 감에게 질문하고 실제 문서에 근거한 답변을 받습니다.
5. 새로운 업무를 맡으면 관련 공문이나 매뉴얼을 업로드합니다.
6. GAM이 문서에서 주요 업무, 일정, 관련 자료를 분석합니다.
7. ‘선생님들의 감’에서 동료 교사의 자료와 경험을 찾아 내 업무에 연결합니다.
8. 처리 과정에서 축적된 자료와 경험을 다음 담당자가 다시 활용합니다.

- 사용 환경: PC웹, 모바일 웹
- 사용 조건: 계정이 필요, 교육청과 연계한 교사들의 사용

## 기술 스택과 실행 방법

- **화면**: React
- **서버·백엔드**: FastAPI(Python)
- **AI**: Claude, ChatGPT(Codex)
- **저장소**: 도커 볼륨
- **배포**: 도커 컴포즈

### 폴더 구조

```text
/ 운영 서버: ai-teacher-01 가상머신, IP 10.56.81.130
/ 프로젝트 경로: ~/Projects/404_200_OK
/ 실행 환경: Docker Compose 기반으로 웹 컨테이너와 API 컨테이너 실행
/ 웹 컨테이너: Nginx를 사용하며 호스트의 8000번 포트로 요청 수신
/ 화면 제공: 기본 경로(/)에서 React·Vite 프로덕션 빌드 제공
/ API 연결: /api/*와 /health 요청을 API 컨테이너로 리버스 프록시
/ API 컨테이너: FastAPI·Uvicorn 기반, 내부 8000번 포트 사용

/ 실행 데이터: backend/data에서 문서 정보와 분석 결과 관리
```

## 작동 범위와 한계, 다음 계획

### 기술적 한계

- 학교별 업무 명칭과 처리 방식이 달라 동일한 업무에도 추가 확인이 필요합니다.  
실제 학교 문서를 다루기 전 접근 권한, 보관 기간, 삭제 절차를 구체화해야 합니다.  
개인정보 마스킹 처리를 주민번호에 대해서만 처리하고 연결되도록 했습니다. 학생이름을 가명으로 처리하기 위한 기능은 다소 미비합니다.  
문서를 파싱하면서 개인정보부분을 local llm을 활용해서 전처리하고 이후 흐름을 진행하고 싶었으나, 컴퓨터의 한계로 하지 못했습니다.

### 다음 계획

- 다양한 학교 공문과 매뉴얼을 활용해 업무·일정 추출 정확도를 검증합니다.  
  
자동으로 생성된 업무와 일정을 사용자가 검토·수정하는 승인 절차를 강화합니다.  
  
학교별로 다른 업무 흐름을 반영할 수 있는 편집 기능을 보완합니다.  
  
문서별 접근 권한과 보관·삭제 정책을 구체화합니다.  
  
실제 교사 사용성 테스트를 통해 업무 파악 시간의 변화를 측정합니다.  
  
교사가 남긴 자료와 경험의 출처·작성 시점·적용 범위를 명확히 표시합니다.
